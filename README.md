# Digital Onboarding

Eenvoudige statische website voor de Digital Onboarding-opdracht van CMD Amsterdam, studiejaar 2026-2027.

## Over dit project

Dit project is een eenvoudige website met meerdere HTML-pagina's, CSS voor de vormgeving en JavaScript voor simpele interactieve onderdelen.

De site helpt studenten stap voor stap door een digitale onboarding, met pagina's over onderwerpen zoals account instellen, wifi, DLO, Teams, rooster, SIS en MijnHvA.

## Structuur

- `index.html` bevat de startpagina
- `page1-account.html` tot en met `page9-finish.html` bevatten de onboarding-pagina's
- `page9-inleveren.html` bevat de inleverpagina
- `css/style.css` bevat de styling
- `js/script.js` bevat de interactieve logica
- `img/` bevat afbeeldingen, iconen en screenshots

## Lokaal openen

Omdat dit een statische website is, is er geen build-stap nodig.

1. Clone of download deze repository.
2. Open `index.html` in je browser.

Gebruik je VS Code, dan kun je de site ook openen via een eenvoudige lokale server, zoals Live Server.
